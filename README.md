## MP3 Tag Reader using c

## Overview

MP3 Tag Reader is a C-based application used to read and display metadata information from MP3 audio files. The project extracts ID3 tags such as song title, artist name, album, genre, and year using file handling and string manipulation techniques.

## Features

* Read MP3 metadata tags
* Display song details
* Extract artist, album, title, and genre
* File handling support
* Simple command-line interface

## Technologies Used

* C Programming
* File Handling
* Structures
* String Manipulation
